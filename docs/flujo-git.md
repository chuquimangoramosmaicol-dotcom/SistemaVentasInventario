# Flujo de trabajo con Git

Este documento forma parte de una actividad de práctica del proyecto SistemaVentasInventario.

## Ramas del proyecto

- main: contiene el código estable del sistema.
- dev: integra los cambios revisados del equipo.
- feature/*: contiene el trabajo de cada actividad.

## Proceso de integración

1. Crear una rama desde dev.
2. Realizar los cambios y registrar commits.
3. Subir la rama a GitHub.
4. Crear un Pull Request hacia dev.
5. Revisar y probar los cambios.
6. Integrar los cambios aprobados.
7. Cuando el desarrollo esté listo, integrar dev en main.
